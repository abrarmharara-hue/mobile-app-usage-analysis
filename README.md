# Mobile App Usage & Screen Time Analysis

Data analysis of mobile app usage and user behavior patterns (10,000+ users).

## 🎯 Objectives
1. Analyze the relationship between notifications and gender.
2. Study the psychological impact of smartphone usage.
3. Compare screen time across 15 countries.

## 💡 Key Insights
* **France** has the highest usage (93.5 mins) — Turkey ranks last.
* **Notifications** are nearly equal between genders (25 vs 25).
* Nearly **one-third of users** report a negative mental health impact.
